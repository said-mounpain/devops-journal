#OPS-102 : Onboarding de deux développeurs

**Contexte.** Amina (backend) et Koffi (frontend) arrivent lundi. Chacun a son propre compte
 : en entreprise, on ne partage jamais un compte.

# on crée d'abord un groupe linux pour les nouveaux arrivants
sudo groupadd equipe

#on vérifie que le group a été créé
getent group

#Création des comptes 'amina' et 'koffi' avec un dossier personnel et le shell '/bin/bash"
sudo useradd -m -s /bin/bash amina
sudo useradd -m -s /bin/bash koffi

#on vérifie si amina et koffi ont bien été créés
said@said:~$ cat /etc/passwd | grep amina
# Résultat: amina:x:1003:1004::/home/amina:/bin/bash
said@said:~$ cat /etc/passwd | grep koffi
# Résultat: koffi:x:1004:1005::/home/koffi:/bin/bash


# Ajout des comptes amina et koffi au groupe 'equipe'
sudo usermod -aG equipe amina
sudo usermod -aG equipe koffi

#on vérifie si amina et koffi sont bien dans le groupe "equipe"
said@said:~$ getent group | grep equipe
#resultat: equipe:x:1003:amina,koffi

#OPS-103 : Le dossier d'équipe

**Contexte.** L'équipe veut un dossier commun pour ses scripts et ses notes :
 `/srv/mboamarket/partage`. Jules, le stagiaire, ne doit ni le lire ni y écrire.

#création du dossier 
sudo mkdir /srv/mboamarket/partage

#Attribution du dossier partage au groupe 'equipe'
chown root:equipe /srv/mboamarket/partage

#modification  des droits du  dossier avec tous les droits pour le groupe et rien pur les autres
 chmod 2770 /srv/mboamarket/partage

#On vérifie que le dossier "partage" a bien été crée avec le groupe "equipe"  yant tous les
# droits et rien pour les autres
said@said:~$ ls -l /srv/mboamarket/
# Résultat: total 24
# -rw-r--r-- 1 root root   5100 Nov  4 19:56 TICKETS.md
# drwxr-xr-x 2 root root   4096 Nov  4 19:56 app
# drwxr-xr-x 2 root root   4096 Nov  4 19:56 config
# drwxrws--- 2 root equipe 4096 Nov  6 23:06 partage
# drwxr-xr-x 2 root root   4096 Nov  4 19:56 uploads


#On test si amina peut créer un fichier 
sudo -u amina touch /srv/mboamarket/partage/amina.txt

#on vérifie si le fichier est bien créé
said@said:~$ sudo ls -l /srv/mboamarket/partage/
# Résultat: total 0
# -rw-rw-r-- 1 amina equipe 0 Nov  6 23:28 amina.txt

#on test si jules peut créer un fichier 
sudo -u jules touch /srv/mboamarket/partage/jules.txt

#On vérifie si jules peut créer un fichier ou pas 
said@said:~$ sudo -u jules touch /srv/mboamarket/partage/jules.txt
# Résultat: touch: cannot touch '/srv/mboamarket/partage/jules.txt': Permission denied
